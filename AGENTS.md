# BotW renderer research

Read [CLAUDE.md](CLAUDE.md) for repository rules, [HANDOFF.md](HANDOFF.md)
for the active checkpoint, and the [research index](docs/research/README.md)
for the research workflow.

Before a rendering module, check existing project notes and search for
prior research across languages. Cite the original work and record what
platform, revision and scene it applies to. Keep developer statements,
original-game capture and static evidence, independent renderer results,
inferences and open questions distinct.

At each milestone, update the relevant module note and capture checklist
with reproducible evidence and the next unresolved check. Record algorithm
and pass behavior before fitting parameters or measuring savings. Follow
the repository's rules for keeping game assets and raw captures local.
